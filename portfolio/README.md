# Portfolio personal — Astro

## Cómo ejecutarlo
1. Descomprimí el ZIP.
2. Abrí la carpeta `portfolio-astro` en VS Code.
3. Abrí Terminal → New Terminal.
4. Ejecutá `npm install`.
5. Después ejecutá `npm run dev`.
6. Abrí la dirección que te muestra la terminal (normalmente http://localhost:4321).

## Fotos
Copiá tus fotos en `public/images/`. En `src/pages/index.astro`, reemplazá cada bloque `.photo-placeholder` por una imagen, por ejemplo:
`<img src="/images/penal.jpg" alt="Pateando un penal" />`

Textos: `src/pages/index.astro`
Colores y estilos: `src/styles/global.css`

Las tipografías Manrope y DM Sans se cargan desde Google Fonts.
